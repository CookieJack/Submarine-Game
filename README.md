# 深海布雷 — 逆向《炸潜艇》

一款 2D 网页街机游戏，把经典《炸潜艇》的视角倒过来：你不再操控海面驱逐舰，而是驾驶深海潜艇，猎杀从左右两侧过境的舰队。开局可选**柴电潜艇**（布设水雷）或**核潜艇**（发射潜射导弹），两种玩法的手感与火力完全不同。

## 运行方式

**零依赖，双击即玩**：直接用 Chrome / Edge / Safari 打开 `index.html` 即可，无需安装、无需联网、无需构建。

也可以在本目录起一个静态服务器：

```bash
python3 -m http.server 8378
# → http://localhost:8378
```

## 操作

| 输入 | 行为 |
|---|---|
| 鼠标移动 | 潜艇受水下惯性与洋流影响，延迟跟随鼠标并保留滑行 |
| 鼠标左键 | 发射当前潜艇武器：柴电潜艇布设水雷，核潜艇发射潜射导弹 |
| P / Esc | 暂停 / 继续 |
| M | 静音切换 |
| Enter / 空格 | 开始任务、进入下一关、结算后重开 |
| 窗口失焦 | 自动暂停 |

## 玩法

- 开局菜单二选一：**柴电潜艇**（默认）或**核潜艇**；本局固定，失败/胜利后可点"更换潜艇"回菜单重选。
- 潜艇有 **3 条命**，被深水炸弹炸中扣 1 条，受击后短暂无敌。
- **柴电潜艇**：水雷上浮到海面后有 **2 秒**待爆窗口；海面驱逐舰的舰体碰到水雷即爆炸。弹仓 **5 枚**，投出后按 1.6 秒一枚逐发回充。
- **核潜艇**：潜射导弹弹仓 **3 枚**，按 5 秒一枚逐发回充；导弹冲出水面后自动锁定 **640px** 内最近的敌舰，命中造成 **2 点伤害**、爆炸半径 **118**。
- 驱逐舰从左、右两侧混编驶入海面，深水炸弹只能从舰尾投放；舰尾经过潜艇上方时会优先投放，并把爆炸深度瞄准潜艇。潜艇需要提前规避。
- 每关是固定的过境编队：**坚持到本关全部敌舰驶离海面即过关**，击沉只影响得分。
- 共 **5 关**，逐关提升敌舰速度、数量与投弹密度；过关维修船体 +1 生命（上限 3）。
- 生命归零则潜艇沉没。

### 潜艇类型

| 潜艇 | 武器 | 特点 |
|---|---|---|
| 柴电潜艇（默认） | 水雷 ×5 | 小巧灵活、速度快、受击判定小；水雷需要上浮到海面待爆 |
| 核潜艇（093A） | 潜射导弹 ×3 | 艇体更大、速度更慢、受击判定更大；导弹可远程自动锁定最近敌舰 |

### 舰船类型

| 类型 | 生命 | 特点 |
|---|---|---|
| 巡逻艇 | 1 | 体积小、速度快、深弹少 |
| 驱逐舰 | 2 | 标准过境单位 |
| 重型驱逐舰 | 3 | 体积大、速度慢、深弹多 |
| 高速变体 | — | 基础速度 ×1.45 ~ ×1.65 |

### 计分

- 每造成 1 点伤害：+40（水雷 1 点即 +40，潜射导弹 2 点即 +80）
- 击沉：巡逻艇 +120 / 驱逐舰 +260 / 重型驱逐舰 +450
- 一次爆炸波及多艘：每多 1 艘 +100
- 过关：+500
- 最高分保存在浏览器本地（`localStorage`）

## 画面与音效

- **霓虹深海**：深蓝渐变海水、动态光柱、海面焦散、海床剪影、海洋雪、远景鱼群。
- 潜艇、驱逐舰、水雷、深弹、爆炸、气泡全部为 Canvas 程序化绘制，没有外部图片。
- 音效由 Web Audio 实时合成（发射、就位、爆炸、受击、回充、过关等），并带极低音量深海环境低鸣。
- 首次点击或按键后启动音频，符合浏览器自动播放策略。

## 技术

- 原生 HTML + CSS + JavaScript，Canvas 2D 渲染。
- 经典 `<script>` 顺序加载，不使用 ES Module / 构建工具，保证 `file://` 双击可运行。
- 逻辑分辨率固定 1280×720，按窗口等比缩放；按 `devicePixelRatio` 提升画布清晰度。
- 无外部图片、字体、音频与网络请求。

### 文件结构

```

js/input.js         鼠标逻辑坐标、点击开火、键盘快捷键
js/fx.js            粒子、气泡、冲击环、浮动文字、震屏、闪光
js/world.js         海水、光柱、海面、海床、海洋雪、远景鱼群
js/entities.js      潜艇 / 水雷 / 潜射导弹 / 深水炸弹 / 驱逐舰

```

## 调参

所有数值集中在 [js/config.js](js/config.js)：

- `CFG.PLAYER`：生命、潜航边界、水下洋流、无敌时长
- `CFG.SUBMARINES`：两种潜艇的速度、推进响应、艇体长度与受击半径
- `CFG.MINE`：水雷弹仓、回充、上浮速度、2 秒引信、爆炸半径
- `CFG.MISSILE`：潜射导弹弹仓、回充、上浮/巡航速度、锁定距离、爆炸半径与伤害
- `CFG.CHARGE`：深弹下沉速度、深度范围、爆炸半径、预警、舰尾过顶判定、提前投放延迟
- `CFG.SHIPS`：三种舰船的生命、速度、投弹配额与分数
- `CFG.LEVELS`：五关编队、入场间隔、速度倍率、投弹密度、舰船航行方向
- `CFG.SCORE` / `CFG.FX` / `CFG.COLORS`：计分、特效上限、色板
