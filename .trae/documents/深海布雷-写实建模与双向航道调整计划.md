# 深海布雷 — 写实建模 / 舰尾投弹 / 双向航道 / 水下惯性 调整计划

## 1. 摘要

本次调整包含四项：

1. **写实化建模**：按现代柴电潜艇（水滴形艇体、围壳舵、X 形尾舵、七叶螺旋桨）与宙斯盾驱逐舰（倾斜艏柱、舰桥、相控阵板、垂发、烟囱、桅杆、机库/飞行甲板）的真实结构重绘潜艇与舰船；保留现有霓虹深海配色与青色轮廓光。
2. **深弹只能从舰尾投放**：深水炸弹的出生点改为舰尾端点，不再在舰体中部或独立海面位置生成。
3. **双向航道**：驱逐舰支持从左往右与从右往左两个方向，关卡编队中混编。
4. **水下惯性/流速**：潜艇改为“目标速度 + 推进响应延迟 + 洋流漂移”的物理式移动，不再瞬间跟随鼠标，并保留停止后的滑行。

不改动：水雷机制、计分、关卡数量、生命/维修规则、音效、UI 布局、`file://` 双击运行方式、零外部资源约束。

## 3. 具体改动

### 3.1 `js/config.js`

#### 3.1.1 玩家潜艇参数（`CFG.PLAYER`）

删除 `FOLLOW`，新增：

| 字段 | 值 | 作用 |
|---|---|---|
| `MAX_SPEED` | `360` | 最大潜航速度（px/s） |
| `ARRIVE_GAIN` | `4.5` | 距目标越近目标速度越低，避免目标点抖动 |
| `THRUST` | `3.2` | 速度趋近期望值的响应率，时间常数约 0.31 秒，产生水下延迟 |
| `CURRENT_X` | `12` | 水平洋流最大流速（px/s） |
| `CURRENT_Y` | `6` | 垂直洋流最大流速（px/s） |
| `CURRENT_PERIOD_X` | `19` | 水平洋流方向变化周期（秒） |
| `CURRENT_PERIOD_Y` | `13` | 垂直洋流方向变化周期（秒） |

保留 `RADIUS`、`INVULN`、`LENGTH`、边界与生命参数不变。

#### 3.1.2 深水炸弹参数（`CFG.CHARGE`）

删除 `AIM_BIAS`，新增/保留：

| 字段 | 值 | 作用 |
|---|---|---|
| `AIM_X_SPREAD` | `190` | 舰尾与潜艇水平距离小于该值视为“舰尾过顶” |
| `AIM_Y_SPREAD` | `80` | 过顶投弹时爆炸深度在潜艇前后随机偏移 |
| `ATTACK_DELAY` | `0.35` | 舰尾进入过顶状态后，最多再等 0.35 秒就投弹 |
| `ATTACK_MIN_ELAPSED` | `0.45` | 距上次投弹至少经过投弹间隔的 45%，才允许提前攻击投放 |
| `DROP_MIN_X` / `DROP_MAX_X` | 保留 `70 / 1210` | 舰尾进入该区间才可投弹 |
| `SINK_SPEED` / `DEPTH_MIN` / `DEPTH_MAX` / `BLAST_RADIUS` / `WARNING` | 不变 | 保持现有威胁与预警节奏 |

#### 3.1.3 舰船参数（`CFG.SHIPS`）

保留 `len/beam/hp/speed/quota/drop/score/fast` 不变，新增 `hullNo` 用于舰体舷号细节：

- `patrol: 'P-7'`

#### 3.1.4 关卡编队（`CFG.LEVELS`）

为每个 `roster` 条目增加 `dir` 字段，`1` 表示左→右，`-1` 表示右→左。每关至少混入 1 艘反向舰，分配如下：

| 2 快速纵队 | `-1, +1, +1, -1` |

### 3.2 `js/entities.js` — 潜艇（`Submarine`）

#### 3.2.1 移动物理（替换现有 `update` 中的 `damp` 跟随）

每帧：

1. 目标点仍为 `Input.mx/my` 并夹在 `MIN_X/MAX_X/MIN_Y/MAX_Y` 内。
2. 计算洋流：
   - `currentX = sin(World.time / CURRENT_PERIOD_X * 2π) * CURRENT_X`
   - `currentY = cos(World.time / CURRENT_PERIOD_Y * 2π + 0.9) * CURRENT_Y`
3. 计算到位速度：
   - `d = hypot(tx - x, ty - y)`
   - `desiredSpeed = min(MAX_SPEED, d * ARRIVE_GAIN)`
   - `desiredVx/Vy = 单位方向 * desiredSpeed`
4. 速度延迟趋近：
   - `k = 1 - exp(-THRUST * dt)`
   - `vx += (desiredVx - vx) * k`，`vy` 同理。
5. 位置积分同时叠加洋流：
   - `x += (vx + currentX) * dt`
   - `y += (vy + currentY) * dt`
6. 边界：撞到 `MIN/MAX` 时夹回并把对应速度分量归零，避免贴边抖动。
7. 朝向与纵倾：
   - `vx > 18` → `facing = 1`；`vx < -18` → `facing = -1`；小速度时保持原朝向，避免临界抖动。
   - `pitch = damp(pitch, clamp(vy * 0.0015, -0.2, 0.2), 6, dt)`，纵倾改为平滑过渡。
8. 螺旋桨气泡改为从新艇尾 `x - facing * 64` 发出，计时不变。

效果：目标点静止时仍有约 0.3–0.5 秒的加速/减速延迟；松手后会滑行约 80–120px；洋流使悬停位置产生轻微横向/纵向偏移，玩家需要主动修正。

`idle(dt)` 保留菜单画面的浮沉动画，不接入洋流。

#### 3.2.2 写实重绘（替换现有 `draw`）

保持局部坐标“艇艏朝 +x”，整体仍由 `translate → rotate(pitch * facing) → scale(facing, 1)` 控制。新增 `hullPath(ctx)` 方法供填充、描边、受击红闪共用。

按下列顺序绘制：

1. **艇艏探照灯**：从艇艏 `+56` 向下前方展开的窄锥形渐变，透明度降为现有的约 60%，避免卡通大光锥。
2. **七叶螺旋桨**：位于 `x = -57`，半径约 11；7 片带后掠角度的桨叶，按 `time * 12` 旋转；外圈不再画夸张的圆环。
3. **X 形尾舵**：在艇尾上下各画一对斜置舵面（约 35°），用深色填充 + 青色细描边。
4. **水滴形艇体**：
   - 用 `hullPath()` 的贝塞尔轮廓替代椭圆：艏部圆钝（最前点 `+58`）、中段近似圆柱（半径约 17）、尾部收缩到 `-56`。
   - 自上而下的三段渐变（顶部受光 `#1d5268` → 中段 `hullMid` → 底部 `hullDark`）。
   - 青色轮廓光保留，透明度约 0.7，线宽 1.1。
   - 顶部追加一条高光弧线。
5. **艇体细节**：
   - 艏部声呐导流罩：艇艏约 `+38 ~ +56` 的浅色区域，用弧形分缝线与主艇体分隔。
   - 鱼雷发射管：艇艏侧面 2 个小型圆角矩形舱门，深色。
   - 侧舷声呐阵列：艇体中下部的长条深色带，内部 6–8 条短分隔线。
   - 消声瓦分缝：5 条淡黑色纵向分缝 + 1 条水平分缝，透明度低，避免抢眼。
6. **围壳（指挥塔）**：
   - 位于艇体前中部（约 `x = 2 ~ 30`），下宽上窄的梯形/圆角结构，高度约 20。
   - 围壳舵：从围壳前缘向艇艏方向伸出的薄翼（侧视呈细长三角形），替代旧版“装饰性小方块”。
   - 桅杆：2 根可升降桅杆（潜望镜 + 通气管），高度约 12–14，端部有小观测头。
   - 围壳顶部 2 个小型深色驾驶窗，内部极弱青光。
7. **信号灯**：围壳后缘一个极弱的青色/琥珀色呼吸灯，不做高亮闪烁。
8. **受击红闪**：用 `hullPath()` 裁剪后填充红色半透明，不再使用椭圆覆盖。
9. **无敌护盾环**：保留现有虚线环。

删除旧版的圆形舷窗、椭圆形艇体、夸张尾鳍与三叶桨。视觉上应能一眼识别为“现代柴电潜艇”，而不是卡通鱼雷。

### 3.3 `js/entities.js` — 驱逐舰（`Destroyer`）

#### 3.3.1 方向字段

构造器新增：

- `this.dir = entry.dir === -1 ? -1 : 1`
- `this.alignedPass = false`
- 出生位置：
  - `dir = 1`：`x = -len/2 - rand(0, 30)`
  - `dir = -1`：`x = CFG.W + len/2 + rand(0, 30)`
- 新增 `sternX()` 方法：`return this.x - this.dir * this.len / 2`（舰尾世界坐标）。

`update()` 中所有位移改为 `this.x += this.speed * this.dir * dt`；离场判定改为：

- `dir = 1`：`x > CFG.W + len/2`
- `dir = -1`：`x < -len/2`

击沉下沉漂移改为 `this.x += this.dir * 8 * dt`。

#### 3.3.2 舰尾投弹与“过顶优先”

`update()` 中替换现有投弹段：

1. 计算 `sternX = this.sternX()`。
2. `aligned = sub 存活 && abs(sternX - sub.x) <= CFG.CHARGE.AIM_X_SPREAD`。
3. 过顶状态机：
   - `aligned` 为真且本舰尚未进入过顶状态（`!alignedPass`）时：
     - 标记 `alignedPass = true`；
     - 若 `quota > 0` 且距上次投弹已过 `interval * ATTACK_MIN_ELAPSED`，则把 `dropTimer` 压缩到最多 `ATTACK_DELAY`（即 0.35 秒后投放）；
   - `aligned` 为假时重置 `alignedPass = false`。
4. 仅当 `quota > 0` 且 `sternX` 位于 `DROP_MIN_X ~ DROP_MAX_X` 时倒计时 `dropTimer`；到点后：
   - `quota--`；
   - `dropTimer = interval * rand(0.85, 1.15)`；
   - 调用 `game.dropDepthCharge(sternX, aligned)`。
5. 不再使用 `this.x` 作为投弹点。

这样深弹出生点永远是舰尾端点：常态按间隔随机投放；舰尾经过潜艇上方时优先打出一枚深度瞄准弹。

`game.dropDepthCharge(x, aimed)` 同步修改：

1. `x = clamp(x, DROP_MIN_X, DROP_MAX_X)`。
2. `aimed` 为真且潜艇存活时，`depth = clamp(sub.y + rand(-AIM_Y_SPREAD, AIM_Y_SPREAD), DEPTH_MIN, DEPTH_MAX)`；否则 `depth = rand(DEPTH_MIN, DEPTH_MAX)`。
3. 水花与音效仍使用传入的 `x`。

#### 3.3.3 尾流/泡沫方向

- 舰尾尾流：`FX.foam(this.x - this.dir * this.len * 0.42, ...)`。
- 在同一个 `wakeTimer` 周期内，额外在舰艏 `this.x + this.dir * this.len * 0.44` 发 1 个小型泡沫，表现艏浪。
- 击沉时泡沫仍以舰体中心为基准，无需改。

#### 3.3.4 写实重绘（替换现有 `draw`）

保持“局部坐标舰艏朝 +x”，在绘制开始时：

```js
ctx.translate(this.x, this.y);
if (this.sinking) ctx.rotate(sinkRatio * 0.22);
ctx.scale(this.dir, 1);
```

新增 `hullPath(ctx)` 与 `drawSuperstructure(ctx, time)` 辅助方法，按 `this.type` 做差异。

通用舰体：

1. **舰体轮廓**：倾斜艏柱、微抬的艏甲板、平直主甲板、垂直/略内倾的方形舰尾。
2. **分层涂装**：顶部亮灰蓝 → 水线暗色 → 舰底近黑；保留青色 1.1px 轮廓光。
3. **舰体细节**：
   - 水线黑带与一条极暗的防污漆分界；
   - 4–5 条纵向钢板分缝；
   - 艏部锚穴与锚链短线；
   - 舰艏声呐导流罩的弧线；
   - 舷号文字：仅 `dir === 1` 时绘制（避免镜像文字），使用 `hullNo`，`7–8px monospace`，低透明度。
4. **上层建筑**（宙斯盾驱逐舰布局）：
   - 前部大型舰桥：斜面艏壁、平顶，顶部驾驶室窗带（4 个小窗，弱青光）；
   - 舰桥两侧各一块八边形/切角相控阵雷达板；
   - 前甲板 8 格 Mk41 垂发舱盖；
   - 舰艏 5 英寸炮塔：多面体炮塔 + 前伸炮管；
   - 中部两组倾斜烟囱（梯形、黑顶、内部极弱橙色余光）；
   - 前桅：三脚桅 + 横桁 + 2 块雷达板 + 鞭状天线，桅顶保留闪烁航灯；
   - 后桅：较矮，带小型旋转雷达条；
   - 中部反舰导弹发射筒：2 根并列斜置圆筒；
   - 舷侧 RHIB 小艇：深色艇体 + 浅色舷圈；
   - 后部机库：低矮长方形上层建筑 + 机库门分缝；
   - 舰尾飞行甲板：甲板线 + 直升机降落圈（“H”），位于舰尾深弹架前方；
   - 近防炮：机库顶部白色雷达罩 + 短炮管。
5. **舰尾深弹架**：在舰尾最末端画一个向下倾斜的小型投放架，架上 2–3 枚深水炸弹圆筒；该位置与 `sternX()` 对齐，让玩家能看出“深弹从舰尾落下”。

按舰种差异：

- `patrol`（巡逻艇）：低矮艇体、单桅、小型舰桥、2 具反舰导弹筒、小口径炮，无机库/垂发/飞行甲板；保留舰尾深弹架。

保留探照灯锥（从舰桥向海面扫）、受击白闪与血条。血条上移到新桅杆/上层建筑之上，避免遮挡。

## 4. 假设与决策

- 美术风格采用用户确认的 **“写实结构 + 保留霓虹光效”**：轮廓、比例、结构写实，但保留青色轮廓光、深海蓝配色与弱发光。
- 深弹威胁采用用户确认的 **“舰尾过顶时优先投放”**：出生点严格在舰尾；只有舰尾进入潜艇上方 ±190px 时才把爆炸深度瞄准潜艇。
- 舰船方向由关卡配置显式指定，而非随机，保证每关都有双向混编、便于后续调参。
- `dir` 只影响移动、出生/离场、尾流与绘制镜像，不改变舰船长度、碰撞盒、速度与分数。
- 潜艇仍只受鼠标控制，不新增键盘/手柄输入；洋流只做轻微位移，不改变边界。
- 所有绘制继续使用 Canvas 程序化图形，不引入图片、字体或网络资源，保持 `file://` 可运行。
- 只改上述 5 个文件（`config.js`、`entities.js`、`game.js`、`README.md`，以及本计划文件），不改动历史计划文档 `.trae/documents/深海布雷-逆向炸潜艇-实现计划.md`。
