# 《深海布雷》（逆向《炸潜艇》）实现计划

## 1. 概要

做一款 2D 网页游戏，是经典《炸潜艇》的镜像玩法：

- 玩家用鼠标操控深海潜艇自由潜航，左键从艇体向上发射水雷。
- 水雷上浮至海面后进入 **2 秒**待爆窗口，海面驱逐舰船体碰到即爆炸。
- 驱逐舰从左向右过境，途中在随机海面位置投放深水炸弹；炸弹下沉至随机深度爆炸，潜艇需规避。
- 潜艇 **3 条命**；每关坚持到本关所有驱逐舰驶离海面即过关（击沉只影响得分）；共 5 关。
- 视觉风格：霓虹深海；技术：Canvas 2D + 原生 JS，**零依赖、双击 `index.html` 即玩**。

## 3. 玩法规格（决策完成）

### 3.1 核心循环

开始界面 → 关卡横幅 → 驱逐舰按时间表从左侧入场 → 玩家布雷 / 规避深弹 → 全部敌舰离场 → 关卡结算 → 下一关（生命 +1，上限 3）→ 第 5 关后胜利；生命归零则潜艇沉没、游戏失败。

### 3.2 操作

| 输入 | 行为 |
|---|---|
| 鼠标移动 | 潜艇以平滑跟随方式在深海区自由移动（有上下左右边界） |
| 鼠标左键 | 从潜艇当前位置向上发射 1 枚水雷（受弹仓与射击间隔限制） |
| P / Esc | 暂停 / 继续 |
| M | 静音切换 |
| Enter / 空格 | 开始游戏、进入下一关、结算后重开（仅对应界面生效） |
| 窗口失焦 | 自动暂停 |

桌面鼠标为唯一输入；不做触屏适配。

**计分**

- 一次爆炸波及多艘：每多 1 艘额外 +100。
- 过关：+500。
- 最高分写入 `localStorage`（`submarine_best`，异常时静默降级）。

### 3.4 判定规则

- 水雷状态机：`rising`（上浮，无碰撞）→ `armed`（海面 2 秒，可触发）→ `sinking`（过期下沉，无碰撞）。
- 水雷触发：`armed` 水雷圆形碰撞体与舰船 AABB（按船体尺寸）相交 → 立即爆炸。
- 水雷爆炸：以海面爆点为圆心，半径 72 内的所有舰船各受 1 点伤害；水雷消耗。
- 舰船受伤：生命 > 0 时继续航行并冒烟；生命 ≤ 0 进入 1.6 秒下沉动画，停止投弹，随后移除。
- 舰船离场：中心 X > 画布宽 + 半船长 → 记为“已通过”，不影响过关。
- 深水炸弹：落到目标深度时一次性判定；潜艇中心在半径 88 内且非无敌 → 扣 1 命并进入无敌。
- 深水炸弹不伤害舰船、不引爆水雷。
- 过关时海面若仍有深弹下坠，立即中和（淡出），避免结算瞬间被炸。

### 3.5 状态机

`menu → intro → playing → levelclear → intro(下一关) … → victory`；任意 `playing` 可进入 `paused`；生命归零进入 `dying`（1.4 秒爆炸动画）→ `gameover`。

- `intro`：1.3 秒关卡横幅，敌舰未生成，输入不生效。
- `playing`：完整更新与绘制。
- `paused`：冻结玩法时间，仅保留背景微动与 UI。
- `levelclear`：显示结算面板；下一关时生命 +1（上限 3）。
- 过关判定：`spawnIndex === roster.length && destroyers.length === 0`，延迟 0.7 秒进入 `levelclear`。

## 4. 技术方案

### 4.1 选型

- 原生 HTML + CSS + JavaScript，Canvas 2D 渲染。
- 所有脚本用经典 `<script>` 顺序加载（非 ES Module），保证 `file://` 双击可运行。
- 固定逻辑分辨率 1280×720，CSS 等比缩放并留黑边适配窗口；按 `devicePixelRatio` 提升画布内部分辨率。
- 无外部图片、字体、音频、网络请求。

### 4.2 文件结构与职责

```
Submarine-Game/
├── index.html          # 舞台、canvas、HUD、全屏界面、脚本顺序
├── README.md           # 运行方式、玩法、操作、关卡、技术说明
├── css/
│   └── style.css       # 霓虹 HUD、屏幕、按钮、缩放与动画
└── js/
    ├── config.js       # CFG、舰船类型、关卡表、色板
    ├── utils.js        # 数学/几何/缓动/格式化工具
    ├── audio.js        # AudioSys：合成音效与环境低鸣
    ├── input.js        # Input：逻辑坐标映射、鼠标/键盘、失焦暂停
    ├── fx.js           # FX：粒子、气泡、冲击环、浮动文字、震屏、闪光
    ├── world.js        # World：海水、光柱、海面、海底、海洋雪、远景鱼群
    ├── entities.js     # Submarine / Mine / DepthCharge / Destroyer 类
    ├── ui.js           # UI：HUD 数值、界面切换、横幅、按钮绑定
    └── game.js         # Game：状态机、生成、碰撞、计分、关卡流程、主循环
```

`index.html` 脚本顺序：`config → utils → audio → input → fx → world → entities → ui → game`，末尾暴露 `window.Game = Game` 便于调试。

### 4.3 关键实现

**渲染与输入**

- `#stage` 居中，`canvas` 的 CSS 尺寸按 16:9 与窗口尺寸取最小值；逻辑坐标恒为 1280×720。
- 实际画布尺寸 `W × dpr, H × dpr`，每帧 `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` 后按逻辑坐标绘制。
- 鼠标逻辑坐标 = `(clientX - rect.left) / rect.width * 1280`，Y 同理；只在 canvas 上监听按下，避免点 UI 时误布雷。
- 主循环 `requestAnimationFrame`，`dt = min((now - last) / 1000, 0.033)`；暂停/失焦时不推进玩法时间。

**绘制顺序**

海水背景 → 光柱 → 海底 → 海洋雪 → 深水炸弹 → 水雷 → 潜艇 → 驱逐舰 → 海面波光 → 爆炸/粒子 → 引导线与引信环 → 暗角/闪光。

**更新顺序**

输入目标 → 潜艇 → 水雷上浮/引信 → 舰船移动/投弹 → 深弹下坠/爆炸 → 碰撞（水雷×舰船，深弹×潜艇）→ 计分/生命 → 关卡生成与过关判定 → FX/UI。

**生成与关卡**

- 关卡开始时把编队展开为累计出场时间表：`spawnTimes[i] = Σ(入场间隔)`，`spawnIndex` 逐帧比对。
- 舰船从 `x = -len/2` 入场，`x += speed × speedMul × dt`，带轻微上下浮动与尾流。
- 深弹投放：按概率在潜艇附近或全屏随机取海面 X，随机目标深度；下坠中显示预测爆炸点，最后 0.45 秒闪烁预警。

**碰撞**

- 圆×旋转矩形：把潜艇/水雷圆心变换到舰船局部坐标后按 AABB 判定（舰船只做轻微纵摇，忽略旋转即可）。
- 水雷爆炸对舰船使用“爆点圆 × 舰船 AABB”判定，遍历所有舰船，支持一雷多杀。

**特效与性能**

- 粒子数组上限约 400，超出时丢弃最旧；气泡、火花、冲击环、浮动文字分别轻量管理。
- 避免大量 `shadowBlur`；辉光用多层半透明描边/径向渐变实现。
- 震屏为 canvas 整体平移 + 衰减，闪光为全屏叠加。

**音频**

- 复用 TD-Game 的 `AudioSys` 模式：`tone()` 扫频、`noise()` 噪声脉冲、`play(name)` 事件表、`toggleMute()`。
- 新增低通滤波噪声用于水下爆炸、持续低频环境音；首次交互初始化。

**最高分**

- `try/catch` 读写 `localStorage`，失败时仅保留内存值。

### 4.4 配置项清单（`config.js`）

**人工试玩**

- 难度：第 1 关深弹压力适中，第 5 关有压迫感但不至于必死。

## 7. 假设与决策

- **不创建 `AGENTS.md`**：仓库为空且该文件不存在，沿用同级游戏工程惯例。
- **不使用 React/Vite/pnpm**：本项目是纯前端街机小游戏，“零依赖双击即玩”优先。
- **关卡制 5 关**：用户选择生存计时过关；用固定编队与逐关增强的速度/投弹密度构成流程。
- **过关奖励生命 +1（上限 3）**：保证 3 条命能撑过 5 关，同时保留紧张感。
- **击沉只影响得分**：漏过不失败，符合“生存计时”选择。
- **深弹投放“随机”含 55% 近潜艇偏置**：否则全屏纯随机命中率过低、缺乏威胁；偏置与散布均在 `CFG` 可调。
- **水雷 1 点伤害、舰船 1–3 点生命**：形成“补刀/预判”节奏；数值可调。
- **一次性水雷、无制导、无其他武器**：严格对应用户描述，不额外扩展鱼雷、导弹、敌方潜艇等玩法。
- **仅桌面鼠标**：不做触屏/手柄/移动端适配。
- **最高分仅本地存储**：无后端、无排行榜、无联网。
- **美术与音频全程序化**：无外部资源文件。

## 8. 风险与边界

- **2 秒引信过短**：用引信环、闪烁灯和布雷辅助线提高可读性；`ARM_TIME` 可调。
- **深弹随机性导致不公平**：提供深度预警环与 0.45 秒引爆预警；偏置概率可调。
- **后期同屏舰船/粒子过多**：粒子设上限、避免高开销模糊；舰船总数受编队限制（最多 6 艘）。
- **`file://` 兼容**：全部经典脚本、无 `fetch`/模块/外部资源；`localStorage` 用 `try/catch` 保护。
- **Canvas 文字模糊**：HUD 全部使用 HTML/CSS，画布只绘制图形与少量浮动文字。
- **失焦/切后台时间跳变**：`dt` 上限 0.033，且窗口失焦自动暂停。
